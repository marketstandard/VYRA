# VYRA yielding-resistance experiment: hybrid KEM and composite signatures under injected component failures

Generated by `cargo run -p vyra-yield --release --bin yield-report`. Do not edit by hand.

## What this is and is not

This is falsification evidence, not a proof. Each cell runs a fixed, finite set of concrete attack strategies against deliberately broken toy components for a finite number of seeded trials. BROKEN means an implemented attack won significantly more often than chance (a concrete, reproducible attack). NO ATTACK FOUND means only that the implemented strategies did not; it is not a security statement, says nothing about attacks not implemented here (in particular generic or cryptanalytic attacks on ML-KEM, HQC, ML-DSA, SLH-DSA, Ed25519 or SHA3, quantum attacks, side channels, multi-user settings, and key-reuse settings beyond the one stripping game), and the failure models are idealised: a real component that fails will fail in its own way. The results complement, and do not replace, the cited GHP18 theorem and the unreviewed proof sketches in docs/SECURITY.md.

## Method (both primitives)

- Master seed: `VYRA-YIELD-U11`. Every trial's randomness is derived from the cell's seed label (JSON `seed` field).
- Verdict: one-sided exact binomial test of H0 `p <= baseline` (IND-CCA2: 1/2; binding and signature games: 2^-128); **BROKEN** iff p-value < 1.000e-6. Otherwise **NO ATTACK FOUND** (never "secure"). Intervals: Wilson score, 99%, on the advantage scale.
- Every cell carries `expected` (what VYRA's documented claims or a named control predict: BROKEN, NO ATTACK FOUND, or UNSPECIFIED) and `expected_basis`.

## Verdicts that contradict their expectation

None: every cell with an expected verdict shows it.

### Failure models (INTENTIONALLY INSECURE)

| model | broken on purpose |
|-------|-------------------|
| Real | none (real component) |
| Leaky | confidentiality: key = SHA3(label, pk, ct), public |
| Malleable | non-malleability: an extra ciphertext byte is ignored by decapsulation |
| KeySubstitutable | MAL-BIND-K-PK: keys carry a tag that decapsulation ignores |
| Constant | everything: the key is a fixed public constant |
| SenderKeyed | HON-BIND-K-CT/K-PK: the encapsulator chooses the key and can re-encapsulate it |

### Games

- **IND-CCA2**: real-or-random key; decapsulation oracle refuses only the exact challenge ciphertext.
- **X-BIND-K-CT / X-BIND-K-PK** (Cremers-Dax-Medinger, as restated by Kraemer-Struck-Weishaeupl, CiC 2(2), Fig. 3): win iff two decapsulations give equal keys (neither an error) while the ciphertexts (K-CT) or public keys (K-PK) differ. HON: honest keys, public keys + oracles; LEAK: honest keys, secret keys leaked; MAL: adversary-chosen secret keys, scenario (I) Decaps-Decaps only.

# Part 2: Signatures

- Transition pair (ML-DSA-44 + Ed25519, the components of VYRA-SIG-2): 200 trials per cell. Dual-PQ pair (ML-DSA-44 + SLH-DSA-SHAKE-128s, the components of VYRA-SIG-PQ1): 12 trials per cell, real SLH-DSA (no stand-in), Vyra and Concat only. Cells: 1410.
- All signature games are search games: baseline 2^-128, BROKEN iff at least one challenger-verified win. With the dual-PQ N, NO ATTACK FOUND is weak evidence (the strategies are deterministic in effect, but N is small).
- `Vyra` runs the real `vyra_sig::CustomComposite` under descriptor id 0x7A (0x7B for the cross-suite target); named suite ids are rejected by that API, so equality with the named suites is shown by a test that rebuilds both from the same components (`tests/sig.rs`).

### Failure models (INTENTIONALLY INSECURE)

| model | broken on purpose |
|-------|-------------------|
| Real | none (real component) |
| Forgeable | EUF-CMA: a public tag XOF(label, pk, ctx, m) always verifies |
| Malleable | SUF-CMA: one extra signature byte is ignored by verification |
| KeySubstitutable | exclusive ownership (S-CEO): public keys carry a 16-byte tag that verification ignores |
| ContextIgnoring | context binding: the half is the default standalone signature (ML-DSA/SLH-DSA empty context, Ed25519 PureEd25519) |
| MessageCollapsing | message binding (MBS): signs a 12-bit digest of the message, so collisions are cheap |

### Games

A message is the pair (M, ctx).

- **EUF-CMA / SUF-CMA**: standard (DFF SAC 2024 Fig. 1, verified).
- **STRIP-COMPOSITE** (ours): a half of an oracle composite signature accepted by some standalone verifier of that component (default mode; context variant with empty context; context variant with a foreign context) on any message.
- **STRIP-STANDALONE** (ours, key reuse): no composite oracle, but standalone signing oracles for both component keys in every mode a deployer could plausibly expose: default (Ed25519: PureEd25519; ML-DSA/SLH-DSA: empty context), the context variant with the empty context (Ed25519: Ed25519ph, ctx ""), and the context variant with any attacker-chosen context *except* the composite's own component context (that query is by definition the composite half and is refused). Adversaries: one per mode (foreign application context; another VYRA suite's context). Any valid composite output wins.
- **S-CEO** (BUFF, CDFFJ S&P 2021, as restated in DFF SAC 2024 Fig. 2, verified against the restatement): an oracle signature verifies the same message under pk' != pk.
- **MBS** (BUFF, same sources, Fig. 3): one signature verifies two different messages under an adversary-chosen key.
- **MIX** (ours): halves of two honest signers verify under a mixed key pkA_1||pkB_2.
- **CROSS-SUITE / CROSS-CONTEXT** (ours): a signature produced for suite byte X (context A) verifies for Y (context B).

### Adversaries

| name | strategy |
|------|----------|
| Garbage | trivial: random bytes as a signature on a fresh message |
| Forge | forge Forgeable halves on a fresh message, reuse the others |
| Collide | find a message whose input collides under the 12-bit collapsing digest; reuse the signature |
| Maul | new signature on a signed message: maul Malleable halves / re-forge Forgeable halves |
| StripHalf-1 | present one half of a composite signature to the standalone component verifier |
| StripHalf-2 | present one half of a composite signature to the standalone component verifier |
| Recombine-Default | assemble a composite from standalone default-mode signatures (Ed25519: PureEd25519; ML-DSA/SLH-DSA: empty ctx) |
| Recombine-EmptyCtx | assemble a composite from context-variant signatures with the empty context (Ed25519: Ed25519ph, ctx "") |
| Recombine-ForeignCtx | assemble a composite from context-variant signatures under a foreign application context |
| Recombine-SuiteCtx | assemble a composite from context-variant signatures under another VYRA suite's composite context |
| SubstituteKey | same signature under a substituted public key (KeySubstitutable halves) |
| Collapse | one signature on two colliding messages under an own key |
| MixHalves | splice halves of two honest signers under a mixed key |
| Relabel | reuse a suite-X signature under suite Y |
| SwapContext | reuse a ctx-A signature under ctx B |
