# Getting help

- **How do I build or run it?** Start with the [README](README.md) quick start
  and [docs/BUILDING.md](docs/BUILDING.md).
- **How does it work, and what is claimed?** See [docs/SPEC.md](docs/SPEC.md),
  [docs/SECURITY.md](docs/SECURITY.md) and [the paper](paper/vyra.pdf).
- **Something is wrong or unclear.** Open an
  [issue](https://github.com/marketstandard/VYRA/issues/new/choose) with the
  template that fits.
- **I found a security problem.** Do not open a public issue; follow
  [SECURITY.md](SECURITY.md).

VYRA is a research prototype maintained on a best-effort basis. There is no
support commitment, and it must not be used to protect real data.
